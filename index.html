Tägliches Briefing per Benachrichtigung

Hinweis: Browser-Benachrichtigungen feuern nur, solange der Tab offen oder der Service Worker aktiv ist. Echte Push-Notifications (auch bei geschlossenem Browser) bräuchten einen separaten Push-Server.

🔑 Anthropic API-Key

Mit hinterlegtem API-Key gehen alle KI-Anfragen direkt vom Browser zu Anthropic — kein Netlify 26s-Timeout, Sonnet 4.6 kann minutenlang generieren (Voll-Dossier, Tiefenanalyse mit Web-Suche, etc.).

Risiko: Der Key liegt in localStorage dieses Browsers. Wer Zugriff auf den Browser hat, kann ihn auslesen. Nutze einen separaten Key mit Limit (Anthropic Console → Settings → Limits) und rotiere bei Verdacht.

↗ Neuen Key erstellen
Tipp: Auf console.anthropic.com/settings/limits kannst du ein Tages-/Monats-Spending-Limit setzen, falls jemand den Key extrahiert. Empfehlung: $5-20/Tag, das reicht für intensive Nutzung dieser App.

➕ Eigenes Element hinzufügen

Erstelle ein eigenes Element auf der Karte. Es bekommt das gleiche Symbol und die gleichen Aktionen (Web-Suche, KI-Analyse, Region öffnen) wie native Elemente. Wird im Browser persistiert (localStorage).
